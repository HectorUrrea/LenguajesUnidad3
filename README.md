# LenguajesUnidad3

Practica 1: Procedimiento
El programa imprime un mensaje al entrar a un procedimiento, mostrando asi la forma en la que funciona la modularizaicon dentro de Ensamblador
y como se utilizan las etiquetas CALL y RET


Practica 2 Escritura en memoria: 
El programa le pide al usuario que escriba su nombre, lo guarda en un buffer y luego muestra el nombre y la cantidad de caracteres que se escribieron.
mostrando como recibir y guardar datos introducidos por el usuario

Practica 3 Validacion:
El programa muestra un mensaje de verificacion si EAX y ECX 


Practica 4 Manejo de Pila:
El programa multiplica dos números pasados por la pila (3 y 25) usando un procedimiento, y deja el resultado en EAX. mostrando como se utiliza la pila
asi como se comporta al acceder a un procedimiento en el cual se utilizan los elementos guardados en ella previamente


Practica 5 MACROS:
El programa usa macros para mostrar dos mensajes y calcular una multiplicación. Este muestra el como se utilizan los MACROS
